# COPD Gene Study Analysis in R

## Overview
This project analyzes COPDGene spirometry and demographic data using R to investigate predictors of long-term lung function decline. The analysis includes data cleaning, exploratory visualization, statistical testing, and regression modeling.

## Skills Used
- R
- ggplot2
- dplyr
- Statistical Modeling
- Data Visualization
- Data Analytics

## Methods
- Data cleaning and preprocessing
- Dataset merging from CSV, JSON, and HTML sources
- Exploratory data analysis
- Welch two-sample t-tests
- Simple and multiple linear regression

## Key Findings
- COPD diagnosis was associated with lower follow-up lung function
- FEV1/FVC ratio showed the strongest predictive relationship with follow-up FEV1
- Age demonstrated a negative relationship with lung function over time
- BMI showed little to no significant relationship with follow-up lung function

## Dataset
Data sourced from the COPDGene research study.
